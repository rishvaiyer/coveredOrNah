# Plan Source Matrix

As of August 19, 2026, Formulary Finder has 17 active New Jersey-focused plan-family baselines. Horizon Marketplace, Ambetter Marketplace, Horizon Classic, AmeriHealth Individual & Family, AmeriHealth Value, AmeriHealth Select, and Wellpoint NJ FamilyCare are included in that count.

These baselines are source-backed reference layers, not member-specific coverage determinations. The static application data is a partial medication-row extraction from each source. For Medicare Advantage, the exact CMS plan workflow should be used whenever a contract, plan, and segment are available.

## Exactness levels

- **Named formulary family:** The source applies to a named market, product, or formulary family. It becomes applicable only after the user's plan is confirmed to use that family.
- **General carrier PDL:** The source is a carrier-level prescribing guide. Employer and benefit variants can differ, so inclusion or absence does not establish exact coverage.
- **Plan-document route:** The source is an official payer route for locating plan documents, not one immutable comprehensive formulary file. Use exact CMS plan data for medication coverage.

## Interpretation rules

- Match insurer, plan or product family, benefit type, formulary year, medication ingredient, strength, dose form, device, and NDC before presenting a result as plan-specific.
- A carrier name alone is not enough to select a baseline.
- `Not listed` is appropriate only when the current source is complete for the confirmed plan family and the exact product match has been checked.
- Missing or unmatched data must remain `Unconfirmed - not a denial`.
- These sources do not establish eligibility, member cost, pharmacy network status, prior-authorization approval, claim payment, or final coverage.
